# 📚 The Miracle of Namiya

This landing page project is dedicated to the novel "The Miracle of Namiya General Store" by Keigo Higashino. The goal was to recreate the book's warm and mysterious atmosphere through a modern web interface.

### Design Focus
- **Visual Storytelling**: Implemented a dynamic night sky using CSS keyframe animations to match the novel's emotional tone.
- **Adaptive Interface**: Designed a responsive layout that ensures a consistent reading experience on both desktop and mobile devices.
- **Typography**: Selected elegant serif fonts to maintain the literary feel and improve overall readability.

### Technical Features
- Built with semantic HTML5 and modular CSS3.
- Utilized CSS Custom Properties for efficient theme management.
- Applied CSS Blend Modes to integrate visual assets seamlessly into the background.
- Optimized UI elements and micro-interactions for better user engagement.

### Project Context
This project was developed for a Web Design course at Hanyang Cyber University (HYCU). It demonstrates the practical application of UI/UX principles and responsive web development techniques.
